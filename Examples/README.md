# Examples

Examples are small, focused AdaEngine projects that demonstrate one feature or API.
Each example must be independently downloadable and openable in AdaEditor.

Complete games and larger reference projects belong in `Samples`.

## Technical examples

[Technical examples](Technical/README.md) are developer studies and validation
projects, available by cloning this repository. They are deliberately absent from
`catalog.json`, Studio recommendations, website cards and catalog release archives.
