# Linux native smoke application

From the AdaExamples root, with the native Linux toolchain and X11/Vulkan dependencies:

```sh
swift run --package-path Examples/Technical/LinuxSmoke LinuxSmoke
```

Resize the window, edit the message, and click the counter. This is a native
window/input check, not a browser preview. See the
[Linux guide](https://github.com/AdaEngine/Ada/blob/main/Documentation/Linux.md).
